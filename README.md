# AI Capstone Project

Early-stage repository for an AI capstone. Application source is not in the tree yet; this file is the onboarding entry point.

## Getting Started

Use this checklist before adding application code.

### Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) LTS (the repo already ignores `node_modules/` and `.env`)
- A code editor such as [Cursor](https://cursor.com/)

### Clone and inspect

```bash
git clone <repository-url>
cd ai-capstone-project
```

Confirm you have Git and Node.js:

```bash
git --version
node --version
npm --version
```

### Local environment

When you add a runtime, keep secrets out of Git:

1. Copy any sample env file to `.env` (create `.env.example` first if one does not exist).
2. Fill in required keys locally. `.env` is listed in `.gitignore`.

There is no `package.json` or start script yet. After those exist, document `npm install` and the exact run command here.
